## Night-mode diagnosis

The original theme button was labeled “Toggle high contrast.” Clicking it added `high_contrast` to the body and changed the canvas to white. The document continued to advertise a light color scheme. Browser reproduction confirmed that reloading removed the setting, and no theme preference was stored.

There was no dark palette to activate. Fixed light backgrounds and dark text colors were scattered through navigation, controls, lesson prose, diagrams, scenarios, formulas, and cards. Changing only the body background would therefore leave inconsistent light panels and unreadable foreground/background combinations.

## Implemented changes

Shared color variables now cover prose, links, muted text, placeholders, controls, borders, navigation, formulas, visual-model cards, misconceptions, scenarios, and page navigation. The night palette retains the blue and warm accents. The intentionally inverted overview hero remains readable in both themes.

The theme button is now a “Night mode” toggle with `aria-pressed`, localized English/Persian labels, and an action tooltip. The preference is applied before styles paint and saved under `hypothesis_testing_course_theme_v1`. Without a saved choice, the course follows the operating system, including live changes. An explicit choice takes precedence. Invalid or unavailable storage falls back safely without disabling reading or toggling.

Native controls receive the appropriate `color-scheme`; focus outlines and control borders use contrasting colors. Printing uses the light palette even when night mode is saved. Existing lesson progress and language preferences remain separate.

Responsive checks also uncovered and repaired three shared problems:

- The hidden skip link positioned 10,000 pixels offscreen created equivalent horizontal overflow in right-to-left layouts. It now uses clipping and a logical position.
- Long lesson titles and Persian completion labels could overflow at tablet widths. Lesson headers now wrap, and completion controls stay within their container.
- Selecting the current lesson from the mobile drawer did not trigger a hash change, leaving the drawer open. Selecting any lesson now closes it. The menu reports its expanded state and supports Escape.

Passing this targeted solid-color audit is not a claim of complete WCAG conformance.

## Shared figure, mobile, and theme requirements

The [course image art direction](illustrations/image_art_direction.md) now governs every recommendation: one concept per figure, no more than four short labels, restrained textbook illustration, consistent paper/ink palette, and generous empty space. Split the broader concepts in the table into separate images when they exceed this budget. The first quality-preview batch follows Lessons 1–5 in lesson order.

Use instructional figures at the explanatory boundaries above, not stock photographs or decorative breaks. Native diagrams and regenerated statistical plots are better suited to this content than browser screenshots or code-to-browser comparisons: this is a statistics course with no visible code examples.

Use full-width figures constrained to the reading column, with HTML captions immediately below. Keep panel labels readable at 320 pixels by stacking panels rather than shrinking a desktop composite. Provide a text description or accessible data table for values essential to the lesson; alt text is a concise explanation, not a substitute for all data.

For diagrams, use semantic theme colors and clear boundaries. For exported plots, prepare checked light/dark variants or a deliberate neutral plotting panel that remains readable in both themes. Labels should meet text contrast targets and informative lines/regions need adequate contrast. Direct labels, line styles, hatching, and symbols must carry meaning alongside color. Avoid blanket inversion, which can alter scientific color legends.

Keep mathematical symbols and numerical axes left-to-right. Localize captions, descriptions, and explanatory labels; review technical terminology and mixed-script ordering in Persian. Scientific graphics should preserve exact data and distinguish observed values, simulations, and schematic illustrations.

The generator now inserts the 15 registered instructional figures and accessible captions; `validate_teaching_html.py` verifies those assets while retaining the exclusion of notebook code, raw outputs, and answer keys. Reusing notebook PNGs unchanged is unlikely to meet narrow-screen, theme, and annotation requirements.
